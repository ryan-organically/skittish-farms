### Link Tracking Setup

```html
<!-- Add to each affiliate link -->
<a href="https://amazon.com/dp/ASIN?tag=skittishfarms-20"
   data-product="ring-stick-up-cam"
   data-page="ring-outdoor-camera-guide"
   onclick="trackAffiliateClick(this)">
   Check Price on Amazon
</a>

<script>
function trackAffiliateClick(element) {
    gtag('event', 'affiliate_click', {
        'product': element.dataset.product,
        'page': element.dataset.page
    });
}
</script>
```
